# طريقة الحصول على الـ APK
1. اعمل Repository جديد على GitHub وارفع كل محتويات الفولدر ده (مع فولدر .github).
2. افتح تبويب Actions ← "Build APK" ← Run workflow.
3. بعد ~5 دقايق نزّل quran-apk من الـ Artifacts، وفيه app-debug.apk. ثبّته على موبايلك.

# الأوفلاين
- المصحف + التفسير الميسر + البحث + الأذكار + المواقيت: شغالين بدون إنترنت تمامًا.
- الصوت: من داخل أي سورة اضغط "⬇️ تحميل الصوت" مرة واحدة (بالقارئ المختار)، وبعدها تسمعها أوفلاين.
